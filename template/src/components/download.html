🔐 Mã Xác Minh Toàn Vẹn (SHA-256 Checksum)

Bạn có thể kiểm tra mã băm SHA-256 sau khi tải để đảm bảo file gốc từ nhà phát triển:

ECFF39F3358CC29307CE77AE5AA8B1653010998E08574ED74F87807A97061EA8
Lệnh kiểm tra mã băm SHA-256:
Windows (PowerShell):
Get-FileHash .\windows-x64.exe -Algorithm SHA256
macOS (Terminal):
shasum -a 256 macos-arm64.dmg
