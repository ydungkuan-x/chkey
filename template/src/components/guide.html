3 Bước Để Bắt Đầu Gõ

Không cần cấu hình phức tạp, tương thích ngay sau khi cài đặt.

1

Tải Bộ Cài Đặt

Tải file cài đặt chính thức windows-x64.exe (v1.0.0) từ website về máy tính của bạn.

windows-x64.exe ~22.6 MB
2

Chạy File Cài Đặt

Nhấp đúp chuột vào file vừa tải về. Bộ cài đặt sẽ tự động sao chép DLL TSF và đăng ký vào Windows trong 2 giây.

Tự động kích hoạt TSF ⚡ Hoàn tất
3

Bấm Win + Space & Gõ

Nhấn tổ hợp phím Win + Space để chọn Native (Rade) và bắt đầu gõ tiếng Tây Nguyên ở bất kỳ đâu!

Phím tắt: Win + Space ✅ RADE Mode
1

Tải File Cài Đặt (.dmg)

Tải gói cài đặt chính thức macos-arm64.dmg (Apple Silicon) hoặc macos-x64.dmg (Intel) về máy Mac.

macos-arm64 / x64.dmg ~18.4 MB
2

Kéo Vào Applications

Mở file .dmg và kéo biểu tượng CHKey vào thư mục Applications. Cấp quyền Trợ năng (Accessibility) trong Cài đặt hệ thống.

Kéo vào Applications ⚡ Cấp quyền Trợ năng
3

Bấm Control + Space & Gõ

Nhấn tổ hợp phím Control + Space (hoặc biểu tượng bộ gõ trên thanh Menu bar) để chọn CHKey Tây Nguyên và gõ ngay!

Phím tắt: Control + Space ✅ CHKey Tây Nguyên
